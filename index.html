Web Elements

Two beautiful, zero-dependency floating components: 1-Click UPI Buy Me a Coffee (0% fees) and Native Web Share.

1-Line Bash Install
curl -sSL https://raw.githubusercontent.com/PurohitBhagyesh/web-elements/main/install.sh | bash
☕

Buy Me a Coffee (UPI)

0% platform fees, instant bank settlement
  • Dynamic QR code generator synced with amount in real time
  • Direct 1-click app links: FamApp, PhonePe, Paytm, GPay, Amazon, WhatsApp
  • Edit Payee Name & UPI ID dynamically via UI or JS API
  • One-click UPI ID copy to clipboard with instant feedback
<link rel="stylesheet" href="buy-me-a-coffee/coffee-upi.css"> <script src="buy-me-a-coffee/coffee-upi.js" data-upi="developer@upi" data-name="Developer Name"></script>
🚀

Native Web Share

Native device sheet & social quicklinks
  • Native OS sheet on iOS, Android & macOS (AirDrop, Messages)
  • Edit share URL, title, and text dynamically via UI or JS API
  • One-click social sharing: WhatsApp, X, LinkedIn, Reddit, Telegram
  • Accessible, keyboard responsive with Escape key handling
<link rel="stylesheet" href="share-link/share-link.css"> <script src="share-link/share-link.js" data-title="My Project" data-url="https://example.com"></script>
