# Security Policy

## Supported Versions

We provide security updates and fixes for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Web Elements, please do not disclose it publicly via GitHub Issues.

Instead, please report security concerns directly to the project maintainer:
- Maintainer: **Bhagyesh Purohit**
- Contact: Open a private security advisory on GitHub or contact via [GitHub Profile](https://github.com/PurohitBhagyesh).

Please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept demonstrating how to reproduce the issue.
- Details regarding affected browsers, operating systems, or versions.

We appreciate your effort in responsibly disclosing issues and will work to address verified vulnerabilities as quickly as possible.
